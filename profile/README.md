# CS2033 Data Communication & Networking

Central repository organization for academic coursework, network calculations, protocol analysis, practical implementations, and weekly notes for CS2033 Data Communication & Networking at the Department of Computer Science and Engineering, University of Moratuwa.

## Organization Repositories

### Course Notes
- [CS2033-Weekly-Notes](https://github.com/CS2033-Data-Communication-Networking/CS2033-Weekly-Notes): Comprehensive weekly lecture notes covering communication models, signal transmission, encoding, modulation, multiplexing, data-link control, and network architectures.

### Lab Assignments & Programming
- [lab-assignment-01-c-primer](https://github.com/CS2033-Data-Communication-Networking/lab-assignment-01-c-primer): C programming primer covering pointers, dynamic memory, linked lists, matrices, and grader boundaries.
- [lab-assignment-02-pcm](https://github.com/CS2033-Data-Communication-Networking/lab-assignment-02-pcm): Pulse Code Modulation (PCM) sampling, quantization, companding, and bit-stream verification in C.

### Network Practicals & Cisco Topologies
- [network-practical-01-ethernet-switching](https://github.com/CS2033-Data-Communication-Networking/network-practical-01-ethernet-switching): Ethernet frame capture, MAC address tables, and switch learning algorithms.
- [network-practical-02-vlans-trunking](https://github.com/CS2033-Data-Communication-Networking/network-practical-02-vlans-trunking): Cisco IOS VLAN configuration, IEEE 802.1Q trunking, and DTP behaviour analysis.
- [network-practical-03-ripv2-routing](https://github.com/CS2033-Data-Communication-Networking/network-practical-03-ripv2-routing): Dynamic routing with RIPv2, passive interfaces, auto-summary, and default route propagation.
- [network-practical-04-nat](https://github.com/CS2033-Data-Communication-Networking/network-practical-04-nat): Static NAT, dynamic NAT address pools, Access Control Lists, and Port Address Translation (PAT).

### Module Laboratories
- [lab-05-ip-addressing](https://github.com/CS2033-Data-Communication-Networking/lab-05-ip-addressing): Departmental IP addressing worksheet, subnetting calculations, and VLSM allocation plans.
- [lab-06-basic-routing](https://github.com/CS2033-Data-Communication-Networking/lab-06-basic-routing): Router interface addressing, static routing, default routing, and connectivity verification.
- [lab-07-wireshark-traffic-analysis](https://github.com/CS2033-Data-Communication-Networking/lab-07-wireshark-traffic-analysis): Live packet capture analysis, display filters, and protocol dissection (ARP, ICMP, DNS, HTTP).

### Organization Workspace
- [.github](https://github.com/CS2033-Data-Communication-Networking/.github): Organization profile and workspace configuration.

## Module Documentation

Weekly learning notes are authored through Notion and maintained in GitHub for version-controlled, durable reference. Topics focus on connecting transmission theory with real-world networking protocols, framing mechanisms, error detection/correction, and network design calculations.

## Engineering & Git Standards

- **Commit Conventions**: All commits adhere to Conventional Commits format (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`).
- **Branching Workflow**: Protocol implementations, socket programs, and simulation configurations utilize dedicated branches before merging into `main`.
- **Documentation**: Packet inspection traces, network topology exports, and calculation derivations are systematically documented.
