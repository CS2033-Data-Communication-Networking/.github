## 📌 About This Organization

This GitHub organization contains the repositories created throughout the **CS2033 Data Communication & Networking** module.

It is not limited to lecture notes. Separate repositories will be maintained for different areas of the module, including:

- Weekly learning notes
- Lecture and tutorial materials
- In-class activities
- Laboratory exercises
- Networking calculations
- Protocol analysis
- Network-design activities
- Packet-capture experiments
- Socket-programming exercises
- Network simulations
- Assignments
- Individual and group projects
- Practical implementations
- Revision resources
- Exam preparation
- Additional experiments and research

The main goal is to create a structured, version-controlled knowledge base that connects the theoretical foundations of data communication and computer networking with practical analysis, configuration, simulation, programming, and implementation.

---

## 🎯 Objectives

This organization is designed to:

- Organize all module-related work in one place
- Track learning progress throughout the semester
- Understand how data is transmitted between devices
- Connect communication theory with real network technologies
- Understand networking models, protocols, and architectures
- Practise networking calculations and problem-solving
- Analyse protocol behaviour and packet structures
- Develop network-design and troubleshooting skills
- Explore wired and wireless communication technologies
- Practise socket programming and network simulations
- Maintain clear documentation for future revision
- Support tutorials, laboratories, assignments, and projects
- Build reusable academic and technical resources
- Develop good Git, GitHub, and documentation practices

## 🗂️ Repository Structure

Each major area of the module may be maintained in a separate repository.

| Repository | Purpose |
|---|---|
| `CS2033-Weekly-Notes` | Weekly notes created and organized through Notion |
| `CS2033-Compendium` | Structured module notes, summaries, diagrams, corrections, and identified knowledge gaps |
| `CS2033-Networking-Calculations` | Bandwidth, transmission delay, propagation delay, data-rate, subnetting, and protocol calculations |
| `CS2033-Protocol-Analysis` | Protocol structures, encapsulation, packet formats, and protocol comparisons |
| `CS2033-Packet-Captures` | Wireshark captures, packet inspections, filtering exercises, and traffic analysis |
| `CS2033-Network-Simulations` | Cisco Packet Tracer and other network simulation activities |
| `CS2033-Socket-Programming` | Client-server programs, socket exercises, and networking code |
| `CS2033-Labs` | Laboratory activities and practical implementations |
| `CS2033-Tutorials` | Tutorial questions, worked examples, and discussions |
| `CS2033-Assignments` | Module assignments and supporting documentation |
| `CS2033-Projects` | Individual and group data-communication and networking projects |
| `CS2033-Revision` | Summaries, comparison tables, cheat sheets, active-recall questions, and exam preparation |

Repository names and structures may change as the module progresses.

## 📝 Weekly Notes Workflow

Weekly learning notes are initially organized in **Notion** and then maintained in GitHub for long-term storage, version control, and accessibility.

Each week may include:

2. Simplified explanations
3. Important definitions
4. Network diagrams
5. Protocol-layer diagrams
6. Packet-format illustrations
7. Communication-flow examples
8. Numerical calculations
9. Subnetting exercises
10. Protocol comparisons
11. Laboratory and tutorial work
12. Packet-capture observations
13. Network-simulation results
14. Common mistakes
15. Knowledge gaps and corrections
16. Additional research
17. Weekly summaries
18. Active-recall questions
19. Revision checkpoints

The notes are not intended to remain as simple copies of lecture material. They will be reviewed, corrected, expanded, and improved continuously as understanding develops.
